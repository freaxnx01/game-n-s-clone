# North & South Clone

A browser-based clone of the classic **North & South** strategy/action game set in the American Civil War.

## ▶️ Play

**[Play it here → https://github.freaxnx01.ch/game-n-s-clone/](https://github.freaxnx01.ch/game-n-s-clone/)**

No install needed — it runs entirely in the browser.

## Running locally

The whole game is bundled into a single `index.html`. To run it locally, either:

- Open `index.html` directly in your browser, or
- Serve it from the repo root:

  ```sh
  python3 -m http.server 8000
  ```

  then visit <http://localhost:8000/>.

## Deployment

The game is deployed via **GitHub Pages** from the `master` branch (root), served on the custom domain `github.freaxnx01.ch`.
